# Rencana: Tambah Package React Native Mobile (Viewer)

## Ringkasan
Menambah package `packages/mobile` menggunakan Expo sebagai React Native client untuk menonton siaran live. Client hanya untuk **viewer** (tanpa admin panel). Menggunakan `react-native-video` untuk playback HLS stream yang sudah di-generate oleh node-media-server.

## Arsitektur

```
stream-broadcast/
  packages/
    shared/       (tetap)
    server/       (tetap)
    client/       (tetap - web)
    mobile/       ← BARU: Expo React Native viewer
```

**Video Protocol:** Server sudah generate HLS via FFmpeg. URL: `http://{server_ip}:10080/live/{streamKey}.m3u8`
- `react-native-video` mendukung HLS natif (AVPlayer di iOS, ExoPlayer di Android)
- Lebih reliable daripada FLV di mobile

## File yang Dibuat

### 1. `packages/mobile/package.json`
- Name: `@broadcast/mobile`
- Dependencies: `expo`, `react-native`, `react-native-video`, `@broadcast/shared`
- Scripts: `start`, `android`, `ios`, `web`

### 2. `packages/mobile/app.json`
- Expo config (name, slug, icon placeholder, splash, android/ios config)

### 3. `packages/mobile/tsconfig.json`
- Extend `../../tsconfig.base.json`
- React Native tsconfig

### 4. `packages/mobile/babel.config.js`
- Expo babel preset

### 5. `packages/mobile/App.tsx` (entry point)
- State sederhana: serverHost, streamKey, connected
- Tampilkan PlayerScreen

### 6. `packages/mobile/src/config.ts`
- Baca environment variables untuk server URL
- Default: `WS_PORT=8081`, `HTTP_FLV_PORT=10080`

### 7. `packages/mobile/src/screens/PlayerScreen.tsx`
- Input stream key (default: "live")
- Input server IP
- Video player menggunakan `react-native-video` (HLS)
- WebSocket connection untuk viewer count & stream status
- Volume control (slider)
- Status indicator (LIVE/CONNECTING/DISCONNECTED)
- Mute/unmute button

### 8. `packages/mobile/src/hooks/useWebSocket.ts`
- Custom hook untuk WebSocket connection
- Handle: `viewer_count`, `stream_end`, `admin_set_volume`, `ping`
- Send: `set_volume`, `ping`

## File yang Dimodifikasi

### 1. Root `package.json`
- Tambah script `dev:mobile`, `build:mobile`

### 2. `.env` + `.env.example`
- Tambah `MOBILE_SERVER_HOST=` (IP server untuk mobile)

## Dependensi Mobile

| Package | Purpose |
|---------|---------|
| `expo` (~52) | Framework React Native |
| `react-native` (0.76) | Core RN |
| `react-native-video` (^6.x) | HLS video player |
| `@broadcast/shared` (workspace:*) | Shared types |

## Alur Data Mobile

```
User input stream key + server IP
    ↓
WebSocket → ws://{server}:8081?stream={key}&username=mobile
    ↓ (viewer_count, stream_end, admin_set_volume)
Video Player → http://{server}:10080/live/{key}.m3u8
    ↓
Volume control → send set_volume via WS
```

## Verifikasi
1. `cd packages/mobile && pnpm install`
2. `pnpm start` → Expo dev server
3. Buka Expo Go di HP (satu network dengan server)
4. Input server IP + stream key, tap Connect
5. Verify video plays HLS stream
6. Verify volume control works
7. Verify viewer count updates
8. Verify disconnect when stream ends
