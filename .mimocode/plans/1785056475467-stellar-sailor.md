# Plan: Docker Compose for Stream Broadcast

## Goal
Create a Dockerfile and docker-compose.yml to run the entire project in a single container with resource limits of 1 CPU core and 1GB RAM.

## Key Findings
- Server serves client's built files as static assets (`packages/client/dist`)
- Build order: shared → server → client (from root `pnpm build`)
- Server needs `ffmpeg` for HLS transcoding
- SQLite DB at `packages/server/data/broadcast.db`
- Ports: 1935 (RTMP), 8080 (HTTP API), 8081 (WebSocket), 10080 (HTTP-FLV/HLS)

## Files to Create

### 1. `Dockerfile` (multi-stage)
- **Stage 1 (builder):** Node 20 + pnpm → install deps → build shared → server → client
- **Stage 2 (runtime):** Node 20 slim + ffmpeg → copy built artifacts → run server

### 2. `docker-compose.yml`
- Single service: `server`
- Build context: `.`
- Ports: `1935:1935`, `8080:8080`, `8081:8081`, `10080:10080`
- Environment: load from `.env`
- Volume: `./data:/app/packages/server/data` (SQLite persistence)
- Resource limits: `cpus: 1`, `memory: 1G`

### 3. `.dockerignore`
- Exclude node_modules, dist, .git, .mimocode, scripts, etc.

## Verification
```bash
docker compose build
docker compose up -d
docker compose ps        # check running
curl http://localhost:8080  # check HTTP API
docker compose down
```
