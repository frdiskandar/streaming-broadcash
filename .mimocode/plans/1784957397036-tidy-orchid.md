# Plan: Manajemen Viewer & Kontrol Volume

## Ringkasan

Menambahkan fitur admin untuk melihat semua viewer yang terhubung, mengontrol volume audio per viewer, dan melihat status menonton. WebSocket diubah menjadi bidirectional agar viewer bisa mengirim state volume ke server.

## Arsitektur

```
Viewer (browser)                    Server                      Admin Dashboard
     │                                │                              │
     │── connect WS ─────────────────►│                              │
     │   (server generate viewerId)   │                              │
     │                                │── broadcast viewer_list ────►│
     │                                │                              │
     │── send {type:"set_volume"} ───►│                              │
     │── send {type:"set_volume"} ───►│── broadcast viewer_list ────►│
     │                                │                              │
     │◄── {type:"admin_set_volume"} ──│◄── admin set volume ────────│
     │   (apply volume to player)     │                              │
```

## File yang Diubah/Dibuat

### 1. `packages/shared/src/index.ts` — Tambah tipe Viewer

```ts
export interface Viewer {
  id: string;
  username: string;
  streamKey: string;
  volume: number;         // 0-100
  isWatching: boolean;
  connectedAt: number;
  lastActiveAt: number;
}
```

Update `WSMessage.type` tambah:
- `"viewer_list"` — server broadcast daftar viewer ke admin
- `"set_volume"` — viewer kirim volume ke server
- `"admin_set_volume"` — server kirim perintah volume ke viewer

### 2. `packages/server/src/services/viewer.service.ts` — Baru

State management untuk viewer:
- `viewers: Map<string, Viewer>` — id → viewer state
- `wsToViewer: Map<WebSocket, string>` — reverse lookup
- `addViewer(ws, streamKey)` → generate ID, store state
- `removeViewer(ws)` → cleanup
- `updateViewerVolume(viewerId, volume)` → update state
- `handleViewerMessage(ws, msg)` → route incoming messages
- `getViewerList()` → return all viewers for admin
- `sendToViewer(viewerId, msg)` → targeted send
- `broadcastViewerList()` → send updated list to admin clients

### 3. `packages/server/src/ws/index.ts` — Modifikasi

- Generate unique viewer ID on connection
- Store viewer state di `viewer.service`
- Tambah `ws.on("message")` handler
- Tambah admin WebSocket connection (subscribe ke viewer updates)

### 4. `packages/client/src/components/ViewerManagement.tsx` — Baru

Panel manajemen viewer di admin dashboard:
- Card grid: 4 kolom desktop, responsive
- Sort: menonton aktif di atas, tidak menonton di bawah
- Setiap card tampilkan:
  - Username / ID viewer
  - Status: Menonton / Tidak (badge hijau/abu)
  - Stream key yang ditonton
  - Terakhir aktif
  - Slider volume control
  - Tombol "Set All" untuk set volume ke semua viewer

### 5. `packages/client/src/components/AdminDashboard.tsx` — Modifikasi
