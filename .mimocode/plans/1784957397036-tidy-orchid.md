# Plan: Autentikasi Stream Key & Manajemen Stream Key

## Ringkasan

Menambahkan autentikasi pada RTMP stream key — hanya stream key yang terdaftar di database yang bisa digunakan untuk streaming. Admin dapat mengelola stream key (CRUD) melalui dashboard admin, termasuk melihat kapan terakhir kali stream key digunakan.

## Arsitektur

```
OBS → rtmp://localhost:1935/live/<streamKey>
         ↓
   node-media-server prePublish event
         ↓
   Cek streamKey di SQLite (stream_keys table)
         ↓
   [Ada] → izinkan streaming, update last_used_at
   [Tidak ada] → tolak (throw error, OBS gagal publish)
```

### 5. `packages/server/src/rtmp/index.ts` — Modifikasi prePublish

Tambah validasi stream key:
```ts
nmServer.on("prePublish", (id, streamPath) => {
  const streamKey = extractKey(streamPath);

  // Cek apakah key ada di database
  const keyData = findStreamKeyByKey(streamKey);
  if (!keyData) {
    console.log(`[RTMP] Rejected: invalid stream key "${streamKey}"`);
    throw new Error("Invalid stream key");
  }

  // Cek apakah key aktif
  if (!keyData.isActive) {
    console.log(`[RTMP] Rejected: stream key "${streamKey}" is disabled`);
    throw new Error("Stream key disabled");
  }

  // Update last_used_at
  updateLastUsedAt(streamKey);

  // Lanjutkan streaming...
  setStreamLive(streamKey);
  broadcast({ type: "stream_start", ... });
});
```
